## 규칙

- **🔴 치명적, ⚠️ 경고만 수정** (💡 제안은 선택)
- "✅ 코드 리뷰 통과" → 추가 작업 없음

## 워크플로우

1. **리뷰 가져오기**

```bash
gh pr view --comments --json comments  # "## 🤖 AI 코드 리뷰" 코멘트 추출
```

2. **분석**: 통과 시 완료, 🔴/⚠️ 발견 시 수정

3. **수정 후 검증**: `./gradlew build`

4. **트러블슈팅 문서** (수정 시 필수)

   - 위치: `.troubles/YYYY-MM-DD_{Topic}.md`
   - 내용: 이슈 설명, 변경 전/후 코드, 해결 상태

5. **보고**: 수정 내역 또는 "수정 불필요"
